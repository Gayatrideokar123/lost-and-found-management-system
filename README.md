# Lost & Found Management System
Frontend: Java Swing | Backend: MySQL | Connectivity: JDBC | IDE: VS Code | Java: 17+

## Setup
1. Install JDK 17+, Maven and MySQL.
2. Run database.sql in MySQL Workbench.
3. Open DB.java and change USER/PASSWORD to your MySQL credentials.
4. Open this folder in VS Code.
5. Run `mvn clean compile`
6. Run `mvn exec:java`
